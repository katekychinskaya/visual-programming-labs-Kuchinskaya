## 4. Освоенные компоненты и блоки

### Компоненты:
- **Label** — текстовые надписи (заголовок, результат, фамилия)
- **TextBox** — поле ввода имени (Hint = «Ваше имя»)
- **Button** — кнопка «Поздороваться»
- **Notifier** — всплывающее уведомление (невидимый компонент)

### Блоки:
- **`when Button1.Click`** — событие нажатия кнопки
- **`if then`** (Control) — условный блок
- **`=` / `≠`** (Logic) — операторы сравнения
- **`join`** (Text) — склейка строк
- **`set Label2.Text to`** (Label2) — установка текста результата
- **`call Notifier1.ShowAlert`** (Notifier1) — показ уведомления
- **`" "`** (Text) — текстовые строки

---

## 5. Логика работы (блоки)

when Button1.Click
do
if Text_Box1.Text = ""
then set Label2.Text to "Введите имя!"
if Text_Box1.Text ≠ ""
then
set Label2.Text to join("Привет, ", Text_Box1.Text)
call Notifier1.ShowAlert("Приветствие отправлено!")

**Что происходит:**
1. Пользователь нажимает кнопку.
2. Если поле **пустое** — в Label2 выводится «Введите имя!».
3. Если поле **не пустое** — в Label2 выводится «Привет, [имя]», **и** показывается уведомление «Приветствие отправлено!».

Kodular — **мощный инструмент** для создания Android-приложений без кода. Он позволяет быстро прототипировать мобильные приложения, хотя требует времени на освоение визуального редактора блоков.
