## 1. Краткое описание выбранного трека

Выбран **Трек C — TypeBot**. В рамках работы создан чат-бот **`lab5-Kuchinskaya-leadgen`** на основе готового шаблона **Lead Generation**. Бот собирает заявки (лиды): имя, email, интересующую услугу, дополнительную информацию и оценку сервиса. Шаблон русифицирован, добавлены новые блоки (Rating, Thank you), условие (Condition по оценке), переменные (`additional`, `rating`) и интеграция **HTTP Request** (POST на `https://httpbin.org/post`). Тема оформления изменена (фиолетовый фон). Бот опубликован по публичной ссылке.

## 4. Освоенные блоки и элементы

| Блок / элемент | Что освоила |
|---|---|
| **Text** | Вывод текстовых сообщений бота |

## 7. Ограничения бесплатного тарифа TypeBot

- **Нет экспорта JSON** — на бесплатном плане кнопка `Export` недоступна. Вместо JSON приложена **публичная ссылка** и **скриншоты**.
- **Брендинг «Made with Typebot»** — внизу бота отображается подпись.
- **Лимит на количество ботов и сообщений** — ограничен (для учебных целей достаточно).
- **Нет кастомных доменов** — доступна только стандартная ссылка `typebot.co`.

## 8. Выводы

В ходе лабораторной работы я освоила **TypeBot** как low-code платформу для создания чат-ботов. Научилась:
- выбирать и русифицировать готовый шаблон;
- работать с блоками (Text, Input, Rating, Condition);
- создавать и использовать переменные (`Name`, `Email`, `additional`, `rating`);
- настраивать условия (Condition) для ветвления сценария;
- делать HTTP-запросы для отправки данных на внешний API;
- менять тему оформления и публиковать бота по публичной ссылке.

Самым интересным было увидеть, как **из готового шаблона** за короткое время можно получить полноценного бота с логикой и отправкой данных. Ограничением стал **бесплатный тариф** — без экспорта JSON и с брендингом, но для учебных целей этого достаточно.

По сравнению с Node-RED и n8n, TypeBot больше ориентирован на **диалоги с пользователем**, а не на автоматизацию процессов — это удобный инструмент для чат-ботов, лидогенерации и сбора обратной связи.
