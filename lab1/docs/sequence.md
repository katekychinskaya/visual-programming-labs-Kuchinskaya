\# Sequence Diagram: Заказ еды с доставкой



```mermaid

sequenceDiagram

&#x20;   participant Клиент

&#x20;   participant Приложение

&#x20;   participant ПлатёжнаяСистема

&#x20;   participant Ресторан

&#x20;   participant Курьер



&#x20;   Клиент->>Приложение: Оформить заказ

&#x20;   Приложение->>Ресторан: Проверка доступности

&#x20;   alt Ресторан доступен

&#x20;       Ресторан-->>Приложение: Подтверждение

&#x20;       Приложение->>ПлатёжнаяСистема: Запрос на оплату

&#x20;       ПлатёжнаяСистема-->>Приложение: Оплата успешна

&#x20;       Приложение->>Ресторан: Начать готовку

&#x20;       Ресторан->>Курьер: Заказ готов к доставке

&#x20;       Курьер->>Клиент: Доставка заказа

&#x20;   else Ресторан недоступен

&#x20;       Ресторан-->>Приложение: Отказ

&#x20;       Приложение->>Клиент: Предложить другой ресторан

&#x20;   end

```
